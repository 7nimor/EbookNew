# سایت کتاب معلم چند پایه

سایت معرفی و دانلود رایگان کتاب "معلم چند پایه (چالش‌ها و فرصت‌ها)" نوشته نیما اورنگی و رضا عباس آبادی

## 📁 ساختار پروژه

```
Ebook new/
├── index.html              # صفحه اصلی
├── 404.html                # صفحه خطای 404
├── README.md               # فایل راهنما
├── assets/                 # پوشه منابع
│   ├── css/                # فایل‌های CSS
│   │   ├── fonts.css      # استایل فونت‌ها
│   │   ├── variables.css  # متغیرهای CSS
│   │   ├── main.css       # استایل صفحه اصلی
│   │   └── error.css      # استایل صفحه 404
│   ├── images/             # تصاویر
│   │   └── logo.png        # لوگو سایت
│   └── fonts/              # فونت‌ها
│       └── IranYekan/      # فونت ایران یکان
└── IranYekan/              # فونت‌های اصلی (پشتیبان)
```

## 🎨 ویژگی‌ها

- ✅ طراحی مدرن و واکنش‌گرا (Responsive)
- ✅ انیمیشن‌های نرم و حرفه‌ای
- ✅ استفاده از فونت ایران یکان
- ✅ تم رنگی سبز
- ✅ صفحه 404 سفارشی
- ✅ بهینه‌سازی برای موبایل و تبلت

## 🚀 استفاده

فقط کافی است فایل `index.html` را در مرورگر باز کنید.

## 📝 اطلاعات کتاب

- **عنوان**: معلم چند پایه (چالش‌ها و فرصت‌ها)
- **نویسندگان**: نیما اورنگی و رضا عباس آبادی
- **لینک دانلود**: در صفحه اصلی موجود است

## 🛠️ تکنولوژی‌ها

- HTML5
- CSS3 (با استفاده از Flexbox و Grid)
- JavaScript (برای انیمیشن‌های Scroll Reveal)
- فونت ایران یکان
